# 프로젝트 한 줄 목표

유료 구독 기반 맞춤형 피드백을 통해 취업 준비생과 현직 전문가를 연결하는 플랫폼

# 1. 문제 **· 사용자**

- 누가 쓸 것인가?
    - 취업준비생
    - 전문지식을 공유해서 부수입을 얻고 싶은 전문가
    - 이력서, 포트폴리오 피드백을 받고 싶은 사람
- 서비스가 무엇을 해주는가?
    - 현직 전문가의 게시글을 읽고 공개 Q&A를 진행한다
    - 유료 구독을 통해 이력서나 포트폴리오 첨삭 및 피드백을 진행한다
    - 전문가와 멘토링

# 2. 역할 및 상태

- 관리자(Admin)
    - 홈페이지 관리 및 회원 관리 / 게시글 관리
- 멘토 (Mentor)
    - 정보 공유 게시글 작성 / Q&A 답변
- 비로그인(Guest)
    - 서비스 둘러보기,전체 공개 게시글 열람
- 일반 회원(User)
    - 일부 공개 게시글 열람
    - 특정 멘토를 구독하면 해당 멘토의 멘토링, 전용 게시글 열람 가능

# 3. 필수 기능(MVP 1)

| **ID** | **기능** | **설명** | **완료 기준** |
| --- | --- | --- | --- |
| F-01 | 회원가입 | 이메일·비밀번호·이름 (역할은 선택 불가, 가입 시 자동 USER 부여) | 비밀번호 암호화 저장 |
| F-02 | 로그인(인증) | JWT 기반 인증 | accessToken, refreshToken 발급 |
| F-02-1 | 소셜 로그인(OAuth) | 소셜 로그인 구글, 카카오 | 소셜 로그인 후 리다이렉트 |
| F-03 | 질문 등록 | 사용자가 질문 등록 | 작성자 자동 기록 |
| F-04 | 질문 목록 | 등록된 질문 정렬 | page, size 파라미터 동작 |
| F-05 | 질문 조회 | 단건 조회 | 조회했을 때 질문 화면 동작 |
| F-06 | 질문 수정/삭제 | 작성자 본인 및 관리자만 수정/삭제 | 타인 수정/삭제 403 |
| F-07 | 답변 등록 | 사용자가 답변 등록 | 로그인 사용자, Answer 저장 |
| F-08 | 답변 수정/삭제 | 작성자 본인 및 관리자만 수정/삭제 | 타인 수정/삭제 403 |
| F-09 | 입력 검증 | 빈 제목·과도한 길이 | 400 + 메시지 |
| F-10 | 프로필 조회 | 본인 프로필 조회 | 인증된 사용자 본인의 상세 정보 조회 |
| F-11 | 프로필 수정 | 본인 이름·관심분야 수정 | 타인 수정 시도 403 |
| F-12 | 회원 탈퇴 | 본인 계정 삭제 | 인증된 사용자 본인만 탈퇴 가능 |
| F-13 | 멘토 신청 | 일반 회원(USER)이 멘토 신청 (승인 전까지 role은 USER 유지) | 이미 대기중인 신청 있으면 재신청 불가 |
| F-14 | 멘토 신청 본인 조회 | 본인의 가장 최근 신청 상태 조회 | 상태(PENDING/APPROVED/REJECTED)+신청일시 반환 |
| F-15 | 멘토 신청 목록 조회 | 관리자가 대기 중인 신청 전체 조회 | ADMIN만 가능 |
| F-16 | 멘토 승인 | 관리자가 신청 승인, role → MENTOR 변경 | ADMIN만 가능 |
| F-17 | 멘토 거절 | 관리자가 신청 거절 | ADMIN만 가능 |
| F-18 | 카테고리별 질문등록 | 카테고리별로 질문 등록 가능 | 카테고리를 드롭다운 형식으로 선택 가능 |
| F-19 | 카테고리별 질문 조회 | 카테고리별로 질문 조회 가능 | 질문 피드 화면 상단에 카테고리별 탭이 노출 |
| F-20 | 프로필 관심분야 등록, 수정 | 프로필 수정을 통해 관심분야 등록, 수정 가능 | 프로필 수정 완료 후 DB와 화면에 선택한 관심분야가 즉시 반영 |

| F-UI-01 | 회원가입 화면 | 게스트(비로그인) | 이메일, 비밀번호, 비밀번호 암호화 저장 처리 |
| F-UI-02 | 로그인 화면 | 게스트(비로그인) | 이메일, 비밀번호 입력후 JWT 인증을 통한 토큰 발급 |

| F-UI-03 | 질문 목록 화면 | 전체 유저 | 등록된 전체 질문 리스트 조회 및 정렬(최신순) |
| F-UI-04 | 질문 상세조회 화면 | 전체 유저 | 등록 질문의 단건 상세 내용 및 목록 조회 |
| F-UI-06 | 질문 수정/삭제 화면 | 작성자 본인/관리자 | 기존 질문 내용 수정 또는 삭제 처리 |
| F-UI-07 | 답변 등록 화면 | 로그인 유저 | 질문 상세 하단에서 새로운 답변 작성 및 등록 |
| F-UI-08 | 답변 수정/삭제 화면 | 작성자 본인/관리자 | 작성된 답변 내용 수정 또는 삭제 처리 |
| F-UI-09 | 입력 검증 및 에러처리 | 전체 유저 | 빈 제목, 과도한 길이 입력, 등 검증 실패 시 400에러 및 메시지 팝업 표출 |
| F-UI-10 | 프로필 화면 | 전체 유저 | 본인 정보 조회·수정, 구독 목록·결제 내역 확인 |
| F-UI-11 | 관리자의 질문·답변 삭제 화면 | 관리자 | 작성자 본인이 아니어도 질문·답변 삭제 처리 |
| F-UI-12 | 멘토 신청·본인 신청 조회 화면 | 로그인 사용자 | 이메일 인증 완료 후 신청 가능, 본인의 신청 상태(PENDING/APPROVED/REJECTED) 조회 |
| F-UI-13 | 멘토 신청 목록·승인/거절 처리 화면 | 관리자 | 대기 중인 신청 전체 조회 및 승인·거절 처리 |
